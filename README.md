# IaAide

Homebrew tap 与安装包下载。安装包在 [Releases](https://github.com/infiniact/homebrew-iaaide/releases)（macOS DMG 已签名公证；Windows 安装包）。

## 安装（macOS）

```bash
brew tap infiniact/iaaide
brew install --cask iaaide
```

## 更新

应用内会自动检查更新（顶部版本号闪烁时点一下即可升级）。也可以：

```bash
brew update && brew upgrade --cask iaaide
```
